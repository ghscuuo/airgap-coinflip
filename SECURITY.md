# Security Policy

## Reporting a Vulnerability

Because this is a critical cryptographic infrastructure tool, security reports are taken extremely seriously. 

To privately submit a security report or cryptographic flaw without exposing it to the public, please use **GitHub Private Vulnerability Reporting**:

1. Go to the **Security** tab of this repository.
2. Click **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a detailed description of the flaw, the affected components, and any proof-of-concept steps or mathematical proofs.

The maintainers will review the report privately in a secure sandbox and coordinate a patch before public disclosure. Do not open a public GitHub Issue for severe cryptographic flaws.
